**مرحبا**

### 🕌 منصة حفظ القرآن الكريم

for english version, please see:
[English](./README.md)


**منصة متكاملة لإنشاء خطط حفظ القرآن الكريم باستخدام التكرار المتباعد، مع دعم اللغتين العربية والإنجليزية، وواجهات REST API، وبنية لتتبع التقدم والتطور.**

**الحالة:** قيد التطوير النشط  
**التقنيات:** TypeScript + Node.js + Express + React + Supabase  
**التركيز:** تنظيم حفظ القرآن الكريم باستخدام دورات مراجعة ذكية ومدروسة.

---

# 🌟 المميزات

## ✅ تخطيط الحفظ
- إنشاء خطط حفظ مخصصة
- تحديد نطاق الآيات
- اختيار مدة الحفظ بمرونة
- أهداف يومية للحفظ والمراجعة
- جدولة مراجعات بالتكرار المتباعد

## ✅ بيانات القرآن الكريم
- دعم كامل لبيانات سور القرآن
- أسماء السور بالعربية والإنجليزية
- التحقق من عدد الآيات
- تصنيف السور (مكية / مدنية)

## ✅ دعم تعدد اللغات
- 🌍 تبديل ديناميكي بين اللغات
- الإنجليزية (LTR)
- العربية (RTL)

## ✅ تجربة المستخدم
- واجهة متجاوبة
- أزرار مدة جاهزة + إدخال رقمي دقيق
- تحسينات في الوضوح وإمكانية الوصول
- إحصائيات مباشرة للخطة

## ✅ البنية الخلفية (Backend)
- بنية REST API
- نظام جاهز للمصادقة
- تكامل مع Supabase
- Middleware للتحقق من البيانات
- تنظيم بالخدمات والطبقات
- واجهات لتتبع التقدم
- معالجة شاملة للأخطاء

التشغيل السريع
التثبيت

قم بجلب المشروع إلى جهازك المحلي:

git clone <your-repository-url>
cd Quran-Memorization-Platform

ثم قم بتثبيت الحزم:

npm install


📄 إعداد البيئة

قم بإنشاء ملف .env داخل المجلد الرئيسي:

SUPABASE_URL=your_url
SUPABASE_ANON_KEY=your_key
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key


🚀 تشغيل بيئة التطوير
npm run dev

سيعمل التطبيق على:

http://localhost:3000

📖 الأوامر المتوفرة
npm run dev
npm run build
npm run start
npm test

🔌 واجهات API
الواجهات العامة

فحص حالة الخادم
GET /health
جلب السور
GET /api/surahs
إنشاء خطة حفظ
POST /api/generate-plan

يدعم:
JSON Body
Query Parameters

مثال:
curl -X POST http://localhost:3000/api/generate-plan \
  -H "Content-Type: application/json" \
  -d '{
    "userId":"user1",
    "surahNumber":2,
    "startVerse":1,
    "endVerse":50,
    "durationDays":30
  }'
